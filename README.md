# TabFlow

Windows 桌面的窗口与标签页管理工具：把散落在浏览器、文件管理器和各种应用里的窗口统一收纳到一个列表里，找出重复的标签页和窗口，一键清理，并支持把特定页面/窗口追踪到 Task 进行分组管理。

## 它能做什么

| 能力 | 说明 |
| --- | --- |
| 浏览器标签页级追踪 | 通过配套浏览器扩展，实时读取 Chrome / Edge 等 Chromium 系浏览器**每个标签页**的标题和 URL，无需重启浏览器、无需调试模式 |
| 文件管理器标签页级追踪 | Win11 文件资源管理器的每个标签页单独统计（真实路径），同窗口同文件夹的多个标签页也能识别为重复 |
| 应用窗口追踪 | 其余可见应用窗口按进程 + 标题收录，可跳转、可关闭 |
| 重复检测与清理 | 按 URL（归一化后）/ 文件路径 / 进程+标题分组找重，支持"一键关闭所有重复"、按组关闭、逐项关闭；新标签页、设置页等内部页面同样计入 |
| Tasks 追踪 | 右键任意条目"追踪到 Task"，用颜色圆点标记；按资源身份（归一化 URL/路径）记录，窗口关掉再开任务标记仍在 |
| 全局搜索 | `Ctrl+Shift+F` 呼出搜索浮层，↑↓ 导航、Enter 跳转到对应标签页/窗口 |
| 实时刷新 | 标签页/窗口变化时后端主动推送刷新，无需手动点刷新 |

数据保存在本地 SQLite（`%APPDATA%\com.tabflow.app\tabflow.db`），不联网上报；扩展与桌面端之间的通信只走本机 `127.0.0.1:19876`，并用持久化配对 Token 鉴权（配对一次，之后自动重连）。

## 环境要求

- Windows 10/11（文件资源管理器标签页级功能需要 Win11；Win10 上资源管理器按窗口级统计）
- [Node.js](https://nodejs.org/) ≥ 18、[pnpm](https://pnpm.io/)、[Rust](https://www.rust-lang.org/)（含 MSVC 工具链）——仅开发/自行构建需要

## 开发运行

```bash
pnpm install
pnpm tauri dev      # 开发模式（热重载）
pnpm tauri build    # 打包安装包
```

后端测试：

```bash
cd src-tauri
cargo test          # 单元测试（涉及真实窗口的 live 测试默认忽略）
```

## 使用方法

### 1. 追踪浏览器标签页（推荐：安装配套扩展）

1. 打开浏览器扩展管理页（`chrome://extensions` / `edge://extensions`），开启**开发者模式**；
2. 「加载已解压的扩展程序」，选择本项目的 `tabflow/extension` 目录；
3. 点击浏览器工具栏的 TabFlow 扩展图标，在弹窗中粘贴配对 Token——Token 在 TabFlow 概览页点击「扩展未连接 · 配对」即可看到（可一键复制）；
4. 配对成功后，概览页会显示 `扩展: chrome(N) · edge(M)`，列表实时展示两个浏览器的所有标签页。

支持同时连接多个浏览器（Chrome、Edge、Brave、Opera、Vivaldi 等 Chromium 系均可，各自安装一次扩展即可）。

> 备选方案：CDP 调试模式。概览页点「窗口模式 · 点击启动调试浏览器」可拉起带调试端口的浏览器实例（Chrome/Edge 136+ 出于安全限制，默认配置文件无法开调试端口，应用会改用隔离配置文件）。功能上不如扩展：隔离配置文件里没有你的登录态和扩展，一般仅在临时测试时使用。

### 2. 追踪文件资源管理器（无需配置）

Win11 下自动按**标签页**粒度统计每个资源管理器窗口里的文件夹，同一窗口内打开多个相同文件夹的标签页会识别为重复。关闭重复的资源管理器标签页时只关那一个标签，不会误杀同窗口的其他标签（通过 UI Automation 定位标签页的关闭按钮）。少数虚拟位置（如"快速访问"）拿不到真实路径时回退为按标题识别。

### 3. 查看与清理重复

- 概览页显示总窗口数、重复数、浏览器/文件夹/应用分项统计；
- 列表页顶部的"重复"区块按组展示重复项，每组默认保留第一个、关闭其余，也可以逐项指定关闭；
- URL 比对前会做归一化：忽略 `http/https` 差异、`#` 锚点、`utm_*` 等跟踪参数和末尾斜杠，所以同一页面的不同推广链接也能识别为重复。

### 4. Tasks 分组追踪

1. 侧边栏 Tasks 区新建任务（可选颜色）；
2. 在列表中**右键**任意条目 → 「追踪到 Task」选择目标任务，条目上会出现对应颜色的圆点；
3. 侧边栏点选任务即可只看该任务下的活窗口。任务记录绑定的是资源身份（归一化 URL / 路径 / 进程+标题），窗口关掉再重新打开，标记会自动恢复。

侧边栏还提供按类型筛选：浏览器标签 / 文件管理器 / 应用窗口。

### 5. 快捷搜索

系统级快捷键 `Ctrl+Shift+F` 随时呼出搜索浮层（TabFlow 不在前台也可以），按标题、URL、路径、进程名过滤，Enter 直接跳转到对应标签页或窗口。

## 工作原理（简述）

- **桌面端**：Tauri 2（Rust 后端 + React 18 前端，Zustand / Tailwind / Radix UI），SQLite 持久化；
- **浏览器标签页**：内置 WebSocket 服务（仅监听 127.0.0.1:19876），MV3 扩展连接后推送全量标签页快照，桌面端下发关闭/激活指令；服务 worker 被浏览器回收断连时，最后一份快照会保留一段宽限期，避免列表闪动；
- **资源管理器**：`IShellWindows` COM 接口枚举每个标签页（STA 线程），关闭单个标签页走 UI Automation；探测不到辅助功能树时会临时激活辅助功能再恢复；
- **应用窗口**：`EnumWindows` + 进程映像名识别；
- **身份模型**：条目用稳定 resource key（归一化 URL / 路径 / 进程+标题）关联任务与重复分组，窗口实例本身随扫描增删。

## 已知限制

- 首次运行下载的 exe 时 Windows SmartScreen 会弹出"Windows 已保护你的电脑"——这是对所有未签名程序的通用拦截，并非安全问题：点击「更多信息」→「仍要运行」即可。彻底消除需要购买代码签名证书；
- 配对 Token 持久化在 `%APPDATA%\com.tabflow.app\extension-token.txt`，配对一次即可，重启桌面端或浏览器后自动重连；如需重置，删除该文件并在扩展里重新粘贴新 Token；
- Chromium 系浏览器多配置文件（profile）同时装扩展时，同一浏览器只显示最后注册的那个 profile 的标签页；
- 完全退出浏览器后，其标签页会在约 90 秒的断连宽限期后从列表消失（用于区分"扩展 service worker 例行回收"与"浏览器退出"）；
- CDP 通道受 Chrome/Edge 136+ 安全策略限制，默认配置文件无法开启调试端口，推荐使用扩展通道；
- 卸载程序**不会**删除以下两个目录中的数据（保留用户配置与历史，重装不丢失）；如需彻底清除请手动删除：
  - `%APPDATA%\com.tabflow.app\` — 数据库（追踪历史、任务、忽略列表）与扩展配对 Token；
  - `%LOCALAPPDATA%\com.tabflow.app\` — WebView2 运行时缓存，可安全删除，下次启动自动重建。

## 目录结构

```
tabflow/
├── src/                  # React 前端（组件、状态、类型）
├── src-tauri/            # Rust 后端
│   └── src/
│       ├── browser.rs    # 扩展 WebSocket 通道（配对、快照、关闭/激活）
│       ├── cdp.rs        # CDP 调试模式备选通道
│       ├── monitor.rs    # 扫描合并（扩展 → CDP → 窗口 → 资源管理器）
│       ├── duplicate.rs  # 归一化与重复检测/清理
│       ├── actions.rs    # 跳转/关闭动作
│       ├── db.rs         # SQLite 持久化
│       └── platform/     # Windows API（EnumWindows、Shell COM、UIA）
└── extension/            # 浏览器扩展（MV3，详见其 README.md）
```
